# FREE DRIVE

ブラウザで遊べる3Dドライブゲームの試作版です。

## 起動方法
GitHub Pages を有効にすると、ブラウザからプレイできます。

1. リポジトリの **Settings** を開く
2. 左メニューの **Pages** を開く
3. **Deploy from a branch** を選択
4. Branch を **main**、フォルダを **/(root)** にして Save
5. 数分待って公開URLを開く

## 操作
- **W / ↑**：アクセル
- **S / ↓**：バック
- **A / ←、D / →**：ハンドル
- **Space**：ブレーキ
- **C**：一人称 / 三人称視点切替
- **1〜3**：車種変更
- **R**：スタート地点に戻る

Three.js は CDN から読み込みます。インターネット接続が必要です。
